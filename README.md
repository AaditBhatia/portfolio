# Personal Portfolio Website

A modern, responsive portfolio website built from scratch with clean HTML, CSS, and JavaScript.

## Features

- 🎨 Modern and clean design
- 📱 Fully responsive (mobile, tablet, desktop)
- ⚡ Smooth animations and transitions
- 🎯 Interactive elements
- 📧 Contact form with validation
- 🌈 Beautiful gradient effects
- 🎭 Parallax scrolling effects
- 💫 Intersection Observer animations

## Sections

1. **Home/Hero** - Eye-catching introduction with call-to-action buttons
2. **About** - Personal information and statistics
3. **Skills** - Technology stack organized by category
4. **Projects** - Showcase of featured projects
5. **Experience** - Timeline of education and work experience
6. **Contact** - Contact form and social links

## Technologies Used

- HTML5
- CSS3 (with modern features like Grid, Flexbox, CSS Variables)
- Vanilla JavaScript (ES6+)
- Google Fonts (Inter)

## Customization

### Update Personal Information

1. Edit `index.html` to update:
   - Name and title in the hero section
   - About section content
   - Skills and technologies
   - Projects information
   - Experience timeline
   - Contact information

### Change Colors

Edit CSS variables in `styles.css`:

```css
:root {
    --primary-color: #3b82f6;
    --secondary-color: #8b5cf6;
    --accent-color: #06b6d4;
    /* ... other colors */
}
```

### Add Images

1. Place your images in the `images/` directory
2. Update image references in `index.html`
3. Replace `.image-placeholder` elements with actual `<img>` tags
