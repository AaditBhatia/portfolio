# Images Directory

Place your images in this directory for use in your portfolio.

## IMPORTANT: Required Image

**REQUIRED**: Add your profile photo as `profile.jpg` in this directory!
The portfolio site is already configured to display it. Save your profile photo with the exact name `profile.jpg` here.

## Recommended Images

- **Profile Photo**: `profile.jpg` (REQUIRED - the site references this!)
- **Project Screenshots**: Add screenshots of your projects
- **Company Logos**: Add logos for companies/organizations you've worked with
- **Technology Icons**: Add icons for technologies you use

## Image Guidelines

- Use optimized images (compress before uploading)
- Recommended formats: JPG for photos, PNG for logos/icons
- Keep file sizes reasonable (under 500KB per image)
- For profile photo: 800x800px or larger, square aspect ratio recommended
- Use descriptive file names (e.g., `project-chatbot.jpg` instead of `img1.jpg`)

## Usage in HTML

To use an image in your portfolio, reference it like this:

```html
<img src="images/your-image.jpg" alt="Description">
```
